# Задание 2. Источники и приёмники данных

| № | Шаг процесса | Источник данных | Тип источника | Приёмник данных | Тип приёмника | Обоснование |
|---|--------------|-----------------|---------------|-----------------|---------------|-------------|
| 1 | Выбор товара | БД каталога сайта | Реляционная БД | Корзина (сессия) | Файловое хранилище / кэш | Структурированные данные о товарах; корзина временная |
| 2 | Оформление заказа | Форма на сайте | API / веб-форма | БД заказов сайта | Реляционная БД | Данные структурированы, нужны транзакции |
| 3 | Создание заказа в OMS | БД заказов сайта | Реляционная БД | OMS | Реляционная БД (OLTP) | Операционная система, нужна целостность |
| 4 | Инициализация оплаты | OMS | Реляционная БД | Платёжный шлюз | SaaS / API | Внешний сервис, обмен через API |
| 5 | Возврат статуса оплаты | Платёжный шлюз | API / вебхук | OMS | Реляционная БД | Асинхронное уведомление, вебхук |
| 6 | Передача заказа в WMS | OMS | Реляционная БД | WMS | Реляционная БД / API | Структурированные данные, интеграция через API |
| 7 | Передача в службу доставки | WMS | Реляционная БД | Курьерская служба | SaaS / API | Внешний сервис, обмен через API |
| 8 | Обновление статуса доставки | Курьерская служба | API / вебхук | OMS | Реляционная БД | Асинхронное обновление статуса |

## Пояснения по типам

- **Реляционная БД** — структурированные данные, схема, транзакции (PostgreSQL, MySQL).
- **API / SaaS** — внешние сервисы, обмен через REST/GraphQL.
- **Вебхук** — асинхронное уведомление от внешней системы.
- **Файловое хранилище / кэш** — временное хранение (Redis, S3).
