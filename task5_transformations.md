\# Задание 5. Примеры преобразований



\## 1. Переименование (renaming)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `customer\_name` |

| Атрибут приёмника | `full\_name` |

| Описание преобразования | Атрибут источника переносится в атрибут приёмника с другим именем. Семантика совпадает, но имена различаются. |

| Пример | `«Иванов Иван Иванович»` → `«Иванов Иван Иванович»` |



\## 2. Приведение типа (type conversion)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `birth\_date` (VARCHAR) |

| Атрибут приёмника | `birth\_date` (DATE) |

| Описание преобразования | Строка преобразуется в тип DATE. Формат источника «DD.MM.YYYY» преобразуется в «YYYY-MM-DD». |

| Пример | `«15.01.1990»` → `1990-01-15` |



\## 3. Нормализация (normalization)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `phone` |

| Атрибут приёмника | `phone\_number` |

| Описание преобразования | Приведение к единому виду: удаление пробелов, скобок, дефисов, символа «+». Остаются только цифры. |

| Пример | `«+7 (999) 123-45-67»` → `«79991234567»` |



\## 4. Вычисление (derivation)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `price`, `quantity` |

| Атрибут приёмника | `total\_amount` |

| Описание преобразования | Новое значение вычисляется как произведение цены на количество. |

| Пример | `price = 1500.00`, `quantity = 3` → `total\_amount = 4500.00` |



\## 5. Сопоставление по справочнику (lookup)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `gender` |

| Атрибут приёмника | `gender\_code` |

| Описание преобразования | Значение источника заменяется значением из справочника: «M» → 1, «F» → 2. |

| Пример | `«M»` → `1` |



\## 6. Разбиение (splitting)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `full\_name` |

| Атрибуты приёмника | `last\_name`, `first\_name`, `middle\_name` |

| Описание | Одно поле разбивается на три. |

| Пример | `«Иванов Иван Иванович»` → `last\_name = «Иванов»`, `first\_name = «Иван»`, `middle\_name = «Иванович»` |



\## 7. Объединение (merging)



| Параметр | Значение |

|----------|----------|

| Атрибуты источника | `country`, `city`, `street` |

| Атрибут приёмника | `address` |

| Описание | Несколько полей объединяются в одно. |

| Пример | `country = «Россия»`, `city = «Москва»`, `street = «Ленина»` → `address = «Россия, Москва, Ленина»` |



\## 8. Маскирование (masking)



| Параметр | Значение |

|----------|----------|

| Атрибут источника | `card\_number` |

| Атрибут приёмника | `card\_number\_masked` |

| Описание | Замена конфиденциальных данных. |

| Пример | `«1234 5678 9012 3456»` → `«\*\*\*\* \*\*\*\* \*\*\*\* 3456»` |
