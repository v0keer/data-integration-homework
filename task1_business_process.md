# Задание 1. Описание бизнес-процесса

## Название процесса
Оформление заказа в интернет-магазине (сквозной процесс: от выбора товара до доставки)

## Участники
- Клиент (покупатель)
- Сайт интернет-магазина (веб-приложение)
- Система управления заказами (OMS)
- Платёжный шлюз (эквайринг)
- Складская система (WMS)
- Служба доставки (курьерская служба)

## Последовательность шагов

1. **Клиент выбирает товар** на сайте и добавляет его в корзину.
   - Данные: ID товара, количество, цена.
   - Система: сайт интернет-магазина (БД каталога).

2. **Клиент оформляет заказ**: указывает адрес доставки, контактные данные, способ оплаты.
   - Данные: ФИО, телефон, email, адрес, способ оплаты.
   - Система: сайт + БД заказов.

3. **Система создаёт заказ** и передаёт его в OMS.
   - Данные: номер заказа, состав заказа, сумма, данные клиента.
   - Система: OMS.

4. **OMS инициирует оплату** через платёжный шлюз.
   - Данные: сумма, номер карты (токенизированный), статус оплаты.
   - Система: платёжный шлюз.

5. **Платёжный шлюз возвращает статус оплаты** в OMS.
   - Данные: статус (успех/неудача), transaction_id.
   - Система: OMS.

6. **OMS передаёт заказ в WMS** для сборки и отгрузки.
   - Данные: номер заказа, состав, адрес доставки.
   - Система: WMS.

7. **WMS передаёт данные в службу доставки**.
   - Данные: номер заказа, адрес, контакты клиента, вес/габариты.
   - Система: курьерская служба (внешняя).

8. **Служба доставки обновляет статус доставки** в OMS.
   - Данные: статус (в пути, доставлен), трек-номер.
   - Система: OMS.

## Какие данные создаются и используются
- Данные о клиенте (ФИО, телефон, email, адрес)
- Данные о товаре (ID, название, цена, количество)
- Данные о заказе (номер, сумма, статус, дата)
- Данные об оплате (статус, transaction_id)
- Данные о доставке (трек-номер, статус, адрес)

## Задействованные информационные системы
- Сайт интернет-магазина (веб-приложение + БД)
- OMS (система управления заказами)
- Платёжный шлюз
- WMS (складская система)
- Система курьерской службы (внешняя)
